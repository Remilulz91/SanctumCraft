## SanctumCraft 0.8.0 — first public release

Build a rune portal, raid a Sanctum floating in the void, dig up a rare egg and get out before it collapses.

### Highlights
- **Rune portal** (any size from 2×3 to 21×21) leading to a procedurally assembled dungeon; every portal recharges on its own.
- **Three difficulties**: Normal, Nightmare and Chaos (Chaos Ticket).
- **Eggs** in hidden nests, heavy to carry, secured only if you get out alive.
- **Loot**: chests by rarity with progressive search, keys and vaults, 12 relics with a classic and a collector version.
- **Danger**: guardians, reinforcement waves, rifts, arrow traps, and a timer that kills everyone left inside.
- **Sanctum Altar**: shop, sell, Hunter levels, talents, relic showcase.
- **Incubator and companions**: hatch your eggs into wolves, foxes, allays or iron golems with random stats and traits, called with a whistle.
- **HUD** (H), **rolling egg** (R), **Sanctum Guide** (Patchouli book, French and English), welcome message and update check.

### Requirements (Minecraft 1.21.1, Fabric)
| Mod | Side | |
|-----|------|-|
| Fabric Loader 0.16.5+ and Fabric API | client + server | required |
| Patchouli 1.21.1-92-FABRIC or newer | client + server | required |
| Mod Menu + Cloth Config | client | optional (config screen) |

### Install
Put `sanctumcraft-0.8.0.jar` and Patchouli in the `mods` folder of the client and of the server.
